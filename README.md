# Проект Sprint_6: Автотесты для учебного сервиса «Яндекс.Самокат»
Тестовые сценарии
1. Выпадающий список в разделе «Вопросы о важном». В тестах проверяется, что когда нажимаешь на стрелочку,
   открывается соответствующий текст. 8 отдельных тестов на каждый вопрос.
2. Заказ самоката. В тестах проверяется весь флоу позитивного сценария с двумя наборами данных.
   Проверяются точки входа в сценарий, их две: кнопка «Заказать» вверху страницы и внизу.
___
## Используемые библиотеки
- pytest
- selenium 4
- allure
___
## Запустить автотесты можно командой ```pytest tests --alluredir=allure_results``` из папки проекта Sprint_6
## Запустить сервер allure командой ```allure serve ./allure_results```
___
## Структура проекта
- tests/ — python package с тестами.
  - test_main_page.py - тесты главной страницы.
  - test_order_page.py - тесты страницы заказов.
  - test_transitions_by_urls.py - тесты переходов.
- locators/ - python package с локаторами.
- page_objects/ - python package с page_objects.
- conftest.py — фикстуры.
- helpers.py — вспомогательные функции.
- urls.py — файл с url.
- data.py — файл с данными.
- README.md - описание проекта
- .gitignore
